# RESEARCH AGENT 5: EXPERIMENTAL WEB ART & NET.ART MOVEMENT

**Research Date**: 2025-11-21
**Portfolio Context**: Johnny Sheng's Creative Portfolio
**Focus**: Browser-native techniques, computational aesthetics, web as artistic medium

---

## EXECUTIVE SUMMARY

This research investigates experimental web art and the net.art movement to inspire browser-native creative techniques for a portfolio that already employs GLSL shaders (Truchet patterns), mix-blend-mode cursors, backdrop-filter glass morphism, and RAF-optimized animations.

The net.art movement (mid-1990s) established core principles: **the browser itself is the canvas**, **web constraints fuel creativity**, and **code is both medium and message**. Contemporary practitioners continue this legacy through generative systems, computational poetry, and works that exploit unique material properties of the web (pixels, blend modes, time, interactivity).

**Key Finding**: The most compelling web art treats browser APIs not as technical specifications but as **expressive materials with poetic potential**.

## SECTION 2: NET.ART PRINCIPLES

### Principle 1: **The Browser is the Canvas, Not the Frame**

Net.art pioneers like JODI revealed that everything typically considered "natural" in browsing—navigation bars, windows, alerts, error messages, source code—is actually highly constructed material available for artistic manipulation. The browser isn't a neutral display vehicle; it's a medium with unique properties.

**Application to Portfolio**:
- View error states as compositional opportunities
- Exploit browser chrome (scrollbars, selection, right-click menus)
- Make the 30px border frame interactive, not just decorative
- Expose underlying structures (show FPS counter, memory usage as aesthetics)

---

### Principle 2: **Embrace Web Constraints as Creative Fuel**

Lynn Fisher's "A Single Div" and ShaderToy's fragment-shader-only approach demonstrate how limitations breed innovation. The web's constraints—bandwidth, browser APIs, screen resolution—aren't obstacles but provocations.

**Application to Portfolio**:
- Challenge: Entire project page from one HTML element
- Challenge: Animation with no JavaScript, CSS only
- Challenge: Shader using only 10 lines of code
- Challenge: Portfolio that works on 2G connection

---

### Principle 3: **Code is Both Medium and Message**

Zach Lieberman's "computation as poetry" and Nick Montfort's generative poems treat code not as means to end, but as expressive material itself. The algorithm is the artwork.

**Application to Portfolio**:
- Display shader source code as visual element (syntax-highlighted backdrop)
- Generative project descriptions (algorithm writes the copy)
- Git commit messages become poetic log
- Comments in code are love letters to future visitors

---

### Principle 4: **Networks and Distribution are Part of the Work**

Rafaël Rozendaal's Art Website Sales Contract ensures his sold works remain publicly accessible. The network nature of the web—its infinite copyability, global reach, ephemerality—isn't a bug, it's a feature.

**Application to Portfolio**:
- Show live visitor count as visual element
- Map where viewers are located geographically
- Display how many times each project has been viewed
- Create art that only works when multiple people visit simultaneously

---

### Principle 5: **Interactivity Creates Co-Authorship**

Bruno Simon's car-controlled portfolio and Everest Pipkin's "Anonymous Animal" make viewers into performers. Web art can be participatory, generative, responsive to input in ways other media can't match.

**Application to Portfolio**:
- Users draw in shader background (trails persist)
- Project images respond to microphone input
- Cursor leaves permanent marks on pages
- Contributors can submit variations on projects

---

### Principle 6: **Time is a Sculptable Material**

Laurel Schwulst's "websites as shifting houses" and Rafaël Rozendaal's infinite loops treat time as medium. Web pages aren't static documents but durational performances.

**Application to Portfolio**:
- Site appearance changes with time of day, season, moon phase
- Projects "age" visually over time since creation
- Loading states become meditative durations, not obstacles
- Archive of past portfolio versions shows evolution

---

### Principle 7: **Digital Materiality Has Unique Aesthetics**

Hito Steyerl's pixelation studies and JODI's glitch art reveal that digital has its own material properties: pixels, compression artifacts, blend modes, color spaces, bit depth. These aren't imperfections—they're the grain of the medium.

**Application to Portfolio**:
- Intentional compression artifacts as style
- Exploit mix-blend-mode beyond current cursor usage
- Color quantization (limit to web-safe palette)
- Dithering as aesthetic (ordered, Floyd-Steinberg)

### B. Canvas API as Artistic Tool

**Particle Systems** (Portfolio uses RAF in Archive.jsx—expand this):
```javascript
class Particle {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.vx = Math.random() * 2 - 1;
    this.vy = Math.random() * 2 - 1;
    this.life = 1.0;
  }

  update() {
    this.x += this.vx;
    this.y += this.vy;
    this.life -= 0.01;
  }

  draw(ctx) {
    ctx.globalAlpha = this.life;
    ctx.fillStyle = 'white';
    ctx.fillRect(this.x, this.y, 2, 2);
  }
}
```

**Application**: Cursor could spawn particles that fade and fall with physics.

const imageData = ctx.getImageData(0, 0, width, height);

**Signed Distance Functions** (ray marching 3D):
```glsl
float sdSphere(vec3 p, float r) {
  return length(p) - r;
}

float sdBox(vec3 p, vec3 b) {
  vec3 d = abs(p) - b;
  return length(max(d, 0.0));
}

// Combine shapes with smooth min
float smin(float a, float b, float k) {
  float h = max(k - abs(a - b), 0.0) / k;
  return min(a, b) - h*h*h*k*(1.0/6.0);
}
```

**Application**: Portfolio background could be 3D raymarched shapes instead of 2D Truchet tiles.

### D. Generative Systems and Procedural Content

**Noise Functions** (Portfolio already uses these in shader):
```glsl
// Perlin noise, Simplex noise, Worley noise, etc.
float n = noise(uv * scale + u_time * 0.1);

// Fractal Brownian Motion (layered noise)
float fbm(vec2 p) {
  float sum = 0.0;
  float amp = 0.5;
  for(int i = 0; i < 6; i++) {
    sum += amp * noise(p);
    p *= 2.0;
    amp *= 0.5;
  }
  return sum;
}
```

**Application**: Each project page has unique generative background based on project ID.

**Generative Text** (Nick Montfort approach):
```javascript
const templates = [
  "The {adj} {noun} {verb} through {place}",
  "{Noun} of {noun}, {verb} with {adj} {noun}"
];

const words = {
  adj: ["shifting", "recursive", "luminous", "temporal"],
  noun: ["pixel", "frame", "shader", "vector"],
  verb: ["flows", "echoes", "cascades", "refracts"],
  place: ["cyberspace", "the canvas", "memory", "time"]
};

function generate() {
  const template = random(templates);
  return template.replace(/{(\w+)}/g, (_, type) => random(words[type]));
}
```

**Application**: Hero page generates new poetic tagline each visit.

**L-Systems** (Algorithmic growth):
```javascript
const rules = {
  'A': 'AB',
  'B': 'A'
};

function iterate(axiom, n) {
  for (let i = 0; i < n; i++) {
    axiom = axiom.split('').map(c => rules[c] || c).join('');
  }
  return axiom;
}

// "A" -> "AB" -> "ABA" -> "ABAAB" -> "ABAABABA"
```

**Application**: Animated line system (Line.jsx) could grow organically using L-systems.

### Takeaway 1: **Implement Multi-Pass Shader Rendering**

**Current State**: Portfolio has single-pass fragment shader (Truchet patterns)

**Next Level**: Add feedback loops using render-to-texture

**Why**: Creates trails, echoes, recursive patterns—organic, evolving beauty

**Implementation** (Three.js):
```javascript
// Create render target
const renderTargetA = new THREE.WebGLRenderTarget(width, height);
const renderTargetB = new THREE.WebGLRenderTarget(width, height);

// Ping-pong between buffers
let currentBuffer = renderTargetA;
let previousBuffer = renderTargetB;

function animate() {
  // Render current frame to buffer
  renderer.setRenderTarget(currentBuffer);

  // Pass previous frame as texture uniform
  shaderMaterial.uniforms.previousFrame.value = previousBuffer.texture;
  shaderMaterial.uniforms.feedback.value = 0.95; // Trail persistence

  renderer.render(scene, camera);

  // Render to screen
  renderer.setRenderTarget(null);
  renderer.render(scene, camera);

  // Swap buffers
  [currentBuffer, previousBuffer] = [previousBuffer, currentBuffer];
}
```

**Effect**: Cursor movement leaves permanent trails in shader background. Patterns echo and decay. Portfolio becomes a canvas users paint on.

**Estimated Time**: 4-6 hours
**Difficulty**: Intermediate
**Impact**: High—transforms static background into living, responsive medium

### Takeaway 3: **Create Time-Based Atmospheric System**

**Current State**: Portfolio looks same at all times of day/year

**Next Level**: Appearance shifts with time of day, season, moon phase

**Why**: Embraces web's temporal nature. Creates reason to revisit. Treats portfolio as "shifting house next to river" (Laurel Schwulst).

**Implementation**:
```javascript
// src/utils/atmosphere.js
export function getAtmosphere() {
  const now = new Date();
  const hour = now.getHours();
  const month = now.getMonth();
  const moonPhase = getMoonPhase(now); // 0-1

  // Time of day
  const timeColors = {
    night: { bg: '#000428', accent: '#a8c0ff', glow: 0.3 },
    dawn: { bg: '#ff6e7f', accent: '#bfe9ff', glow: 0.8 },
    day: { bg: '#f0f0f0', accent: '#4facfe', glow: 0.5 },
    dusk: { bg: '#434343', accent: '#fa709a', glow: 0.7 }
  };

  const timeOfDay =
    hour >= 5 && hour < 7 ? 'dawn' :
    hour >= 7 && hour < 19 ? 'day' :
    hour >= 19 && hour < 21 ? 'dusk' : 'night';

  // Season (Northern Hemisphere)
  const season = month < 3 || month === 11 ? 'winter' :
                 month < 6 ? 'spring' :
                 month < 9 ? 'summer' : 'autumn';

  const seasonModifiers = {
    winter: { saturation: 0.7, hueShift: -20 },
    spring: { saturation: 1.2, hueShift: 10 },
    summer: { saturation: 1.5, hueShift: 20 },
    autumn: { saturation: 1.0, hueShift: -10 }
  };

  return {
    colors: timeColors[timeOfDay],
    season: seasonModifiers[season],
    moonPhase,
    description: `${season} ${timeOfDay}`
  };
}

function getMoonPhase(date) {
  // Simplified lunar phase calculation
  const year = date.getFullYear();
  const month = date.getMonth() + 1;
  const day = date.getDate();

  let c = 0, e = 0, jd = 0, b = 0;
  if (month < 3) {
    year--;
    month += 12;
  }
  c = Math.floor(year / 100);
  jd = Math.floor(365.25 * year) - c + Math.floor(c / 4) +
       Math.floor(30.6 * (month + 1)) + day - 694039.09;
  jd /= 29.5305882;
  b = Math.floor(jd);
  jd -= b;
  return jd;
}
```

### Takeaway 4: **Build Session Memory & Progressive Disclosure System**

**Current State**: Every visit is identical

**Next Level**: Portfolio "remembers" visitors, reveals deeper layers over time

**Why**: Rewards repeated engagement. Creates sense of relationship between visitor and work. Long-time viewers unlock hidden content.

**Implementation**:
```javascript
// src/utils/sessionMemory.js
export class SessionMemory {
  constructor() {
    this.visits = parseInt(localStorage.getItem('portfolio_visits') || '0');
    this.firstVisit = localStorage.getItem('portfolio_first_visit') || Date.now();
    this.projectsViewed = JSON.parse(localStorage.getItem('projects_viewed') || '[]');
    this.secretsFound = JSON.parse(localStorage.getItem('secrets_found') || '[]');
    this.totalTime = parseInt(localStorage.getItem('total_time') || '0');

    this.incrementVisits();
    this.startTimer();
  }

  incrementVisits() {
    this.visits++;
    localStorage.setItem('portfolio_visits', this.visits);
    if (!localStorage.getItem('portfolio_first_visit')) {
      localStorage.setItem('portfolio_first_visit', Date.now());
    }
  }

  startTimer() {
    this.sessionStart = Date.now();
    window.addEventListener('beforeunload', () => {
      const sessionTime = Date.now() - this.sessionStart;
      this.totalTime += sessionTime;
      localStorage.setItem('total_time', this.totalTime);
    });
  }

  viewProject(projectId) {
    if (!this.projectsViewed.includes(projectId)) {
      this.projectsViewed.push(projectId);
      localStorage.setItem('projects_viewed', JSON.stringify(this.projectsViewed));
    }
  }

  findSecret(secretId) {
    if (!this.secretsFound.includes(secretId)) {
      this.secretsFound.push(secretId);
      localStorage.setItem('secrets_found', JSON.stringify(this.secretsFound));
      this.triggerSecretAnimation(secretId);
    }
  }

  getUnlocks() {
    return {
      // Milestones
      firstVisit: this.visits === 1,
      returningVisitor: this.visits >= 2,
      regularVisitor: this.visits >= 5,
      devotedVisitor: this.visits >= 10,
      enlightenedVisitor: this.visits >= 25,

      // Completionist
      allProjectsViewed: this.projectsViewed.length === 6,
      allSecretsFound: this.secretsFound.length === 10,

      // Time-based
      daysSinceFirst: Math.floor((Date.now() - this.firstVisit) / (1000 * 60 * 60 * 24)),
      totalHours: Math.floor(this.totalTime / (1000 * 60 * 60)),

      // Special unlocks
      unlockShaderControls: this.visits >= 3,
      unlockSourceCode: this.allProjectsViewed,
      unlockDevTools: this.secretsFound.includes('konami-code'),
      unlockTimeMachine: this.visits >= 10
    };
  }
}

// Usage in App.jsx
import { SessionMemory } from './utils/sessionMemory';

function App() {

  const unlocks = memory.getUnlocks();

  return (

      {unlocks.devotedVisitor && <ThankYouEasterEgg />}
      {unlocks.unlockShaderControls && <ShaderControlPanel />}
      {unlocks.unlockTimeMachine && <VersionArchive />}

      {/* Regular content */}
    </div>
  );
}
```

const blendModes = [
  'normal', 'multiply', 'screen', 'overlay', 'darken', 'lighten',
  'color-dodge', 'color-burn', 'hard-light', 'soft-light',
  'difference', 'exclusion', 'hue', 'saturation', 'color', 'luminosity'

function CyclingBlendElement({ children }) {
